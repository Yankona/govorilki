# Сказки в живом чтении: что проверено и что можно

Проверено 2026-11-08 (первый раз) и повторно с поиском по открытым API (тот же день). Повторять раз в месяц:
`python3 dev/tools/tales/find_recordings.py` (LibriVox, Internet Archive, Викисклад; пишет в `dev/tales/found/`, не в git).

Правило: в игру идёт только то, где свободны И текст, И запись (исполнение). Всё остальное — в таблицах «не взято».

## Что показали открытые API

* **LibriVox** (librivox.org/api/feed/audiobooks): всего 85 книг на русском (все — общественное достояние: волонтёры сами отдают
  записи; на archive.org у каждой стоит Public Domain Mark / CC0). Поиск по авторам Пушкин, Крылов, Ушинский, Бажов, Мамин-Сибиряк,
  Одоевский, Аксаков, Ершов, Гаршин, Андерсен, Перро, Гримм, Киплинг, Толстой, Жуковский, Афанасьев и др. новых русских книг,
  кроме перечисленных ниже, не нашёл: **у LibriVox нет русских записей Крылова, Ушинского, Бажова, Мамина-Сибиряка, Одоевского
  («Городок в табакерке»), Аксакова («Аленький цветочек»), русских Андерсена/Перро/Гримма и Киплинга.** Всё, что есть по детским
  и сказочным темам, — ниже.
* **Internet Archive** (advancedsearch, русское аудио, явная лицензия CC0 / CC BY / CC BY-SA / PD в поле licenseurl): из 350 найденных
  72 с открытым licenseurl; из них сказки/детское — только LibriVox-выпуски, Андерсен в чтении Каретина (CC BY, см. «не взято»),
  «Complex Numbers: Русалочка» (CC BY-SA, но это современная музыкальная студийная постановка 2 часа, не чтение сказки),
  «Волшебник Изумрудного города» (CC BY 3.0, но текст Волкова под охраной до 2047 г.). Остальное — политика, лекции, подкасты.
* **Викисклад** (категории русской речи): 39 звуковых файлов; сказок нет (отдельные слова, интервью, голоса, музыка). Файл
  «Ru-Теремок (сказка).ogg» (CC BY 3.0) — произнесённое слово, а не сказка. Ничего не взято.

Как проверено, что запись читает тот самый текст, что на экране: распознавание речи (faster-whisper small, `asr.py`) расшифровывает файл;
`recordings.py` сам выбирает по записи вариант текста на странице Викитеки и берёт запись только если слова текста узнаются
не меньше чем на 75 % (по факту 76–95 %; остальное — ошибки распознавания) и скорость речи правдоподобна (1–3,8 слова в секунду:
так отсеивается запись из нескольких сказок против одного варианта). Те же времена слов дают начало каждого предложения.
Из файла вырезаны вступление LibriVox, название и приписка «Записано в … губернии».
Файл: моно MP3 32 кбит/с, 24 кГц (около 0,24 МБ в минуту); все 31 записи ≈ 68 МБ, самый большой файл 5,4 МБ (лимит Cloudflare Pages 25 МБ).

Отказались сами записи по проверке (оставлены в списке на будущее): «Свинья и волк, петух и лиса» (запись читает не вариант
из Викитеки), «Лиса, первая сказка» (длинный файл из нескольких сказок, нужен другой текст).

## Возраст на карточке (решение 2026-11-08)

На карточке сказки стоит «N+» (нижняя граница `age[0]`); ребёнок младше N−1 видит такую сказку в разделе «Для детей постарше».
Афанасьев в оригинале бывает жестоким; страшные сказки — с 8–9 лет, ничего «слишком жестокого» не убрано: нигде нет подробностей
расправы, всё решается волшебством или хитростью героя. Сатира Щедрина — для школьного чтения (10+).

| Сказка | Возраст | Причина |
|---|---|---|
| Овца, лиса и волк | 4+ | короткая, без насилия |
| Лутонюшка, Конь-скатерть-рожок, Семь Семионов, Медведь на липовой ноге | 5+ | добрые чудеса, лишь тень угрозы (медведь крадёт овец) |
| Мизгирь | 6+ | паук губит мух; в конце «голову отсекли на плахе» — шуточный похоронный перечень |
| Иван-дурак, Свинка золотая щетинка, Сивко-бурко | 6+ | герой-«дурак» побеждает; «убил сорок оводов», режет клячу для волшебной шкуры |
| Мужик, медведь и лиса | 6+ | лису «разорвали собаки» (одна фраза) |
| Удалой батрак | 6+ | смешной, волки съедают лошадь |
| Волк и коза (раньше 5+) | 6+ | волка сжигают в избушке |
| Баба-яга — вторая сказка (Филюшка) и четвёртая (девочка и гребешок), Василиса Поповна | 7+ | погоня Бабы-яги, «съесть хотела», но спасаются |
| Баба-яга и жихарь (первая), третья сказка, Иван-царевич и Марфа-царевна, Кощей Бессмертный | 8+ | Баба-яга жарит жихаря, ломает падчерицу («косточки гремят»), змии, смерть Кощея — страшно, но с победой |
| Лихо одноглазое | 9+ | людоед-великанша съедает портного, герой выжигает ей глаз — самая жуткая; оставлена с 9 лет |
| Гаршин: Сказка о жабе и розе, Attalea princeps, То, чего не было | 9+ | печальные, философские (смерть розы и пальмы), не жестокие |
| Салтыков-Щедрин: Премудрый пискарь, Самоотверженный заяц, Как мужик двух генералов прокормил, Дикий помещик | 10+ | сатира, смерть и страх «премудрого» пискаря; для школьного возраста |

## Как добавить ещё

1. `python3 dev/tools/tales/find_recordings.py` — что нового. Скачать нужный файл с archive.org по одному (пауза 2 с, UA без личных данных)
   в отдельную пустую папку; `python3 dev/tales/asr.py файл.mp3` (faster-whisper, модель small) — слова с временем.
2. Страница Викитеки с текстом (`action=raw`, не чаще 1 запроса в 3–4 с: иначе 429) в папку; запись в `dev/tales/recordings.json`.
3. `python3 dev/tales/recordings.py ПАПКА_С_ЗАПИСЯМИ ПАПКА_С_ТЕКСТАМИ` → `dev/site-add/tales/` (mp3, тексты, оба index.json).
   Отказы с причиной печатаются; опубликованные (есть в `tales/audio/index.json`) пропускаются, `--all` — переделать все.
4. Тесты: `tests/tales_rec.js`, `tests/books.js`; ударения для голоса игры при релизе — `build/say_ru.py`.
