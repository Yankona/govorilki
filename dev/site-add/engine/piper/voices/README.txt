The Russian voice «Руслан» of Govorilki: the Piper model ru_RU-ruslan-medium (rhasspy/piper-voices, copy from
https://huggingface.co/diffusionstudio/piper-voices, md5 731eb188e63b4c57320e38047ba2d850, 63 201 294 bytes), served from
this site so that no third party sees the players' addresses. Cloudflare Pages takes files up to 25 MB, so the model is
cut into three equal parts (split -n 3); the game joins them in the browser and checks each part against voices.json (sha-256).
Model card: dataset RUSLAN corpus, https://ruslan-corpus.github.io/, licence CC BY-NC-SA 4.0
(https://creativecommons.org/licenses/by-nc-sa/4.0/); training: piper (MIT), finetuned from the lessac voice.
