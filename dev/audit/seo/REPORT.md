Везде (www, игра, манифест, JSON-LD) обещание «бесплатно, без покупок» — при подписке переписывать на 4 языках. Google Fonts в исходнике игры есть, но в собранном `/play/ru/` сторонних `<script src>`/`<link href=https://…>` нет — шрифты свои (GDPR-риск в DE снят).

## 6. Монетизация

Код: `подписк` 0, `paywall` 0, донат 0, `premium` 1 (регэксп голоса), `Stripe` 4 (CSS). В BACKLOG/PRODUCT — ничего.
Cloud D1: `families(login, salt, pin_hash HMAC, meta ≤40 KB, locks…)`, `kids(login,id,upd,profile ≤600 KB)`, `tokens(hash,…)`, `ipfails`, `config`, `relay` (12 ч шифротекст), `moves`, `ideas`, `stats_day/month`. Маршруты `/v1/ping, move, stats, idea(s), check, family, login, meta, pin, logout`. Нет: email, личности взрослого, юрисдикции, тарифа, покупок, вебхуков.
Не хватает для платного плана: (1) личность взрослого — email magic link или Apple/Google; 4-значный код — не защита оплаченного аккаунта; (2) merchant of record (Paddle/Lemon Squeezy/FastSpring) — НДС/OSS по 27 странам, чеки, возвраты; со Stripe это на авторе; (3) `entitlements` в D1 + проверка в воркере + вебхук + офлайн-кеш права (подписанный билет); (4) условия, цены, возвраты, финальная политика (сейчас черновик), Impressum (§5 DDG), регистрация и НДС; (5) согласие родителя по GDPR ст. 8 — пульт с кодом = шлюз, не согласие; (6) переписать «без покупок» на 4 языках везде; (7) в магазинах — только IAP (Apple 3.1.1)/Google Billing, 15–30 %.
Экспозиция сейчас низкая; слабые места — черновик политики без контакта, нет Impressum, микрофон/камера без экрана согласия взрослого. Первый шаг — добровольная поддержка без права в игре.

- Микрофон (7716) и камера (7066) → Apple 5.1.4 (политика + COPPA/GDPR); Google — раскрыть в Data safety; AAID/геолокации нет — хорошо.
- Анонимные шахматы без чата (24345) → Google «Social features»: контроль взрослого есть («взрослый разрешает один раз»).
- «для детей» в названии → Apple 2.3.8: только Kids Category.
- Веб-обёртка → Apple 4.2 Minimum Functionality; Google «should not be just a webview» — TWA офлайн-PWA обычно проходит, для Families риск выше.
Минимум: шлюз перед внешними ссылками (или убрать YouTube/Google из детских экранов), финальная политика с контактом, Data safety/IARC, Bubblewrap + `assetlinks.json`; для Apple — Capacitor и разговор про 4.2.
